# Current-horizon catcher utility and separate setup efficiency

Run `python tools/catcher_efficiency.py --uid <uid> --cache <verified-cache> --level 30 --output-dir <private-dir>` (or `--species` for an offline roster scenario). This produces the original utility card, an independent False Swipe companion, JSON reports and ZIP. It reads account state twice and refuses successful delivery if Caught or Seen IDs changed. It never writes player state. Reports and individualized artifacts belong outside public git.

## Different questions, different numbers

`catcher_now` remains the Prismatic Standard/current-horizon authority: one best major status, safe HP control, limited utility, actual owned donor/Sketch setup and ordinary ability assumptions. Tier and Attack never enter utility points. The new module leaves that ranking untouched. Its companion compares expected DAMAGE ACTION attempts to bring a full-HP benchmark to 1 HP, including misses; it does not calculate throws, capture probability, total battle duration or survivability.

Default comparison: attackers at the stated ceiling; Pikachu, Roggenrola, Magnemite, Gastly and Hoppip at L20; IV31/EV0/neutral nature on both sides, base forms, full-HP healthy attacker, ordinary ability variants. These are reproducible benchmarks, not observed wild levels, individual stats or proof that the owner has a particular ability/retained kit. Attacker IV0/EV0/Attack-down and IV31/EV252/Attack-up endpoints show sensitivity with fixed target assumptions. Species stats/types/ordinary slots come from the verified historical Gen VII source used by the project. Hidden abilities are not promoted into owned scenarios.

The bounded damage model excludes critical hits, held items, stat stages, field effects, defender abilities, retaliation, healing, PP limits and switching/status/ball costs. It implements the noncritical False Swipe stages, half-down Q12 rounding, Normal STAB/Adaptability, Technician/Tough Claws, Huge/Pure Power/Hustle, conditional Guts/Toxic Boost, burn and explicit Rivalry scenarios. Unsupported offensive abilities fail visibly. Conditions not modeled are not evidence of safety against every wild target. Real Prismatic battle-engine equivalence is unverified; stock model agreement is not native bit identity.

## Nonlethal dynamic program

For HP h > 1 and independent damage rolls d, a successful False Swipe moves to max(1,h-d); misses and zero rolls self-loop. Solve E[h] = (1 + sum(p_d * E[max(1,h-d)])) / P(progress), with E[1]=0. No progress returns JSON null/impossible, not zero actions. Ghost immunity blocks both Normal moves until a separately sourced bypass is available.

When the selected obtainable kit contains Super Fang, a second column in the JSON computes the optimal damage-only policy between False Swipe and current-HP halving, accounting for Fang's accuracy. It NEVER allows Fang at 1 HP. This does not silently give another creature Fang or add a fourth early Sketch slot. A Ghost-bypass variant may need replacing a selected move; acquisition/copy budget still applies. Spore/powder and sleep immunities, Effect Spore poisoning risk and Butterfree's inability to learn False Swipe remain visible on the utility card.

Parasect is an explicitly optional L24 evolution of an owned Paras only after Spore at L22, with retained moves checked. It has the same utility kit, not extra catching points for its Attack. Smeargle Own Tempo and Technician are separate unconfirmed normal-slot scenarios. Stronger standalone HP carriers still need a status partner and are not thereby superior solo catchers.

Package integrity and test scope are recorded in the fixture. Artificial ability overrides exercise arithmetic, NOT species ownership/legality. Tests compare every damage roll without installing the reference package or consulting mutable network data. The runtime implementation is Python stdlib; Pillow is only for the existing card renderer. The provenance is separate from the historical species/learnset source.

The pinned-reference damage tests and analytical nonlethal/miss/impossible/one-HP cases run offline.
