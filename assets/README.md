# Asset sources

## Pokémon icon atlas

`gen7-icons.png` contains National Dex entries 001–807 in row-major order, with 32 columns of 40×30 pixel frames. It is generated by `tools/build_icons.py` from the Generation VII menu icons in the [PokéAPI sprites repository](https://github.com/PokeAPI/sprites), pinned to commit `6e3e7c43e86db0e1b2277795cfee41b11e8df2a4`. Normal generation reads the external verified cache; use `python tools/build_icons.py --refresh` to download inputs.

The repository's license text is preserved at `references/PokeAPI-sprites-LICENCE.txt`. As that notice states, the image contents are copyright The Pokémon Company. This project uses them for a personal, non-commercial fan checklist.

Location image provenance is recorded with the encounter dataset and comes from `references/Wild Pokemon Locations.pdf`.
